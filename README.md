# Dental Clinic — Bhandup West, Mumbai

A modern, production-grade dental clinic website engineered for high performance, accessibility, SEO excellence, and smooth patient experience.

## Features

- **Modern Healthcare Design System:** Built with Primary Navy (`#12304A`), Teal Accent (`#278C87`), Off-white (`#F7F9FC`), and Pale Mint (`#E5F3F1`).
- **Mobile-First Responsive Layout:** Zero horizontal overflow tested across mobile, tablet, and desktop viewports (320px – 1440px).
- **10 Core Treatment Pages:** Dedicated SEO-friendly routes for Root Canal, Dental Implants, Teeth Cleaning, Braces & Aligners, Teeth Whitening, Crowns & Bridges, Gum Treatment, Tooth Extraction, Wisdom Tooth Treatment, and Pediatric Dentistry.
- **Appointment Request Flow:** Form validation with appointment date selection, session slot, treatment choice, and clear status feedback.
- **Google Reviews Carousel:** Interactive carousel featuring 6 patient reviews with 5-star ratings, designations, and verified indicators.
- **Embedded Google Map:** Interactive location map for Bhandup West, Mumbai with quick navigation shortcuts.
- **Floating WhatsApp Action:** Custom-positioned button with gentle periodic pulse animation and responsive offsets.
- **Accessible FAQs:** Accessible accordions with keyboard support across all pages.
- **SEO & Structured Data:** Schema.org JSON-LD (`Dentist` and `MedicalProcedure`), XML Sitemap, and `robots.txt`.

## Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router, Static Generation)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Language:** TypeScript
- **Icons:** [Lucide React](https://lucide.dev/)
- **Typography:** Inter & Manrope (Google Fonts via `next/font`)

## Getting Started

First, install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the site.

## Production Build

To build the static production export:

```bash
npm run build
npm run start
```
